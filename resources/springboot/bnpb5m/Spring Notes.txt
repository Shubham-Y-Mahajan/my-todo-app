minikube has 1 cluster(1 master node + 1 worker node)

cluster  -- group of nodes
node  -- physical machine / VM's

Master Node a.k.a Control plane -- Manage the clusters and make decisions

Master Node contains:
1) API Server  -- Entry point for all the request hitting k8
2) Controller- manager
3) Scheduler
4) etcd server -- Brain of K8 -- state info in key-value pair.

Worker Node Contains:

1) POD -- Smallest Deployable Unit which has one or more containers
2) Container Runtime  : Docker engine
3) Kubelet  -- monitor the pods and give info to the control plane

Create the job and paste this pipeline script:

pipeline {
    agent any 
    tools {
	jdk  'Java17'
        maven 'Maven'
    }
    stages {
        stage('checkout from git hub') { // A logical section of the pipeline
            steps {
                
                echo 'Pull application from github'
		git branch: 'main', credentialsId: 'gitcred', url: 'https://github.com/chnt/bnp5.git'

            }
        }
        stage('build the project') {
            steps {
                echo 'create jar file using maven'
                bat 'mvn clean package' 
            }
        }
        stage('Build the Docker Image') {
            steps {
                echo 'Build the Docker Image for SB application...'
                bat 'docker build -t pms-app:latest .'
            }
        }

       stage('Start the minikube') {
            steps {
		echo 'Deleting Minikube'
		bat 'minikube delete'
                echo 'Starting Minikube'
		bat 'minikube start'
                
            }
        }
        stage('Load the image to  minikube') {
            steps {
                echo 'Load the image to  minikube'
                bat 'minikube image load pms-app:latest'
            }
        }
        stage('Deploy the appln to k8') {
            steps {
                echo 'Deploy the appln to k8'
		bat 'kubectl apply -f k8s/'

		echo 'checking pods'
		bat 'kubectl get pods'

		echo 'checking services'
		bat 'kubectl get svc'
                
            }
        }
	stage('Wait for the pods to be ready') {
            steps {
                echo 'Load the image to  minikube'
                bat 'kubectl wait --for=condition=Ready pods --all --timeout=180s'
            }
        }

	stage('Access the application') {
            steps {
                echo 'Accessing the URL'
                bat 'minikube service pms-service --url'
            }
        }
    }
    post { 
        always {
            echo 'Pipeline finished.'
        }
        success {
            echo 'Pipeline succeeded!'
        }
        failure {
            echo 'Pipeline failed!'
        }
    }
}
